# Клиент

Клиент представляет собой CLI-приложения для взаимодействия с сервером `gophkeeper`.

## Сборка клиента
- под macOS: `make build-darwin`, доступные флаги: `VERSION` и `COMMIT`;
- под linux: `make build-linux`, доступные флаги: `VERSION` и `COMMIT`.

(Оставил mvp-бинарники под обе операционки в руте как пример, далее уберу).

## Процесс взаимодействия с клиентом
1. Собираем бинарный файл под нужную ОС (если необходимо);
2. Запускаем бинарный файл: `./<bianry_name>`;
3. Указываем адрес сервера;
4. Используем приложение.
